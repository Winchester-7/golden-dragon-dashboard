# Golden Dragon: дашборд ИИ-анализа ресепшена (макет)

Интерактивные макеты панели. Все цифры, имена, разговоры и отметки камеры условные.

Во всех вариантах есть: смены администраторов (день 08:00–20:00, ночь 20:00–08:00),
кто сейчас на смене, оценка ИИ по каждому администратору отчёт после каждой смены, раздел «Телефон» (звонки с SIM, звонки и переписки WhatsApp служебного телефона с выводами ИИ) и раздел «Камера» с живым просмотром веб-камеры
(показывает камеру, подключённую к компьютеру, на котором открыт дашборд).

- Вариант 1 (основной): https://winchester-7.github.io/golden-dragon-dashboard/
- Вариант 2, дизайн v28 (в запасе): https://winchester-7.github.io/golden-dragon-dashboard/new/
- Вариант 3, дизайн v21: https://winchester-7.github.io/golden-dragon-dashboard/v3/
- Вариант 4, тёмное стекло (дизайн v7): https://winchester-7.github.io/golden-dragon-dashboard/v4/

Исходный код (React + Vite): `source/` для варианта 2 (сборка в `new/`),
`source-v3/` для варианта 3 (сборка в `v3/`), `source-v4/` для варианта 4 (сборка в `v4/`).
