# Golden Dragon: панель ИИ-контроля ресепшена (макет)

Интерактивный макет панели на React 19 + Vite. Дизайн и анимации взяты из шаблона Dashboard v28, тексты и экраны переделаны под отель. Все цифры, разговоры и письма условные.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # готовая сборка в dist/
```

## Разделы

Главная, Отчёты, Все разговоры, Беседы, Проблемные, Записи, WhatsApp, Почта, Booking, Настройки.

## Где что лежит

- `src/data/hotel.js`: все демо-данные (разговоры, письма, отзывы, меню).
- `src/pages/`: страницы разделов.
- `src/components/`: виджеты главной, плеер записи, разбор разговора.
- `src/styles/gd.css`: стили, добавленные для отеля. Остальные стили из шаблона.
